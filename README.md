# Harsh Rana, portfolio

Static site, no build step. Open `index.html` or host it on GitHub Pages.

- `index.html`, `style.css`, `main.js`: the whole site
- three.js is loaded from the jsDelivr CDN (see the import at the top of `main.js`)
- The 3D character is built in code inside `main.js`, there are no model files

To change the text, edit `index.html`. To change where the character stands and what he does in each section, edit `POSES` at the top of `main.js`.
